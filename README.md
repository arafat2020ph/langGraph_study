# My AI & LLM Learning Workflow 🚀

This repository contains my hands-on practice notebooks and mini-projects while learning Python, LangChain, and Local LLMs (Ollama).

## 📂 Contents

Here is a brief overview of the notebooks in this repository:

- **`agentic_rag (from previous project)`**: Simple RAG implementation using Ollama.
- **`customer_support.ipynb`**: A basic customer support chatbot workflow.
- **`creat_fb_post.ipynb`**: An LLM application to generate Facebook posts.
- **`streming.ipynb`**: Practice notebook for implementing streaming responses with LLMs.
- **`prectis_1.ipynb` & `prectis_2.ipynb`**: General practice notebooks for LangChain/LLM concepts.
- **`bmi.ipynb`**: Basic Python logic practice (BMI calculator).
- **`conditional.ipynb`**: Python conditional statements practice.

## 🛠️ Setup Instructions

1. Clone the repository.
2. Create a virtual environment: `python -m venv venv`
3. Activate it: `venv\Scripts\activate` (Windows)
4. Install dependencies: `pip install -r requirements.txt`
5. Create a `.env` file and add your API keys (e.g., `OPENAI_API_KEY=...`).
6. Open the notebooks in Jupyter or VS Code and run them.
